## 课程修读与流程要点

### 1. 课程定位与选题机制
- 本课设是《控制系统仿真与CAD》的集中实践延续；所谓 CAD 本质上是利用 MATLAB 开展数值求解与控制仿真，与绘图 CAD 软件无关；
- **8 选 2 选题机制**：共提供 8 个选题，每人必须自主选做其中 2 个题目，每个题目 50 分，合计 100 分；
- 本仓库完整涵盖了两个典型选题的全套源码与排版报告（选题 2：Bode 图频域校正；选题 5：直线一级倒立摆 LQR 状态反馈控制）。

### 2. 代码编写与排版建议
- **MATLAB 与 AI 辅助**：MATLAB 算法代码与公式求解完全可以借助现代 AI 辅助完成自动编写，省时省力；关键是理解控制系统的物理意义与指标含义；
- **报告排版**：报告采用现代排版引擎 Typst 编排，源码见 `reports/typst_src/`，排版严整清晰。

### 3. 考核与答辩
- 平时考勤签到占 30%，打印成册的纸质课设报告占 70%；
- 结课时有简短的现场答辩讲解，老师会要求简述自己做了什么内容、调节了什么参数、曲线指标如何，讲清自己做的内容即可顺利通过。
